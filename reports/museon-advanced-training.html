01

MUSEON 如何記錄一個人的認知資產

任何 SaaS 工具記錄的是「動作」；MUSEON 記錄的是「判斷邏輯」——這是根本差異。

認知資產化：MUSEON 的核心命題

當一位資深業務離職，帶走的不是聯絡簿——是她十年累積的「判斷感」：哪個客戶能快速成交、哪種情況要讓步、哪類問題要升報。這些「判斷感」從來無法被 CRM 記錄。

「MUSEON 是你的第一個不會離職的主管。」
它把最值錢、也最脆弱的東西——人的判斷——接住了。
🧠

認知能力記錄

透過持續對話，MUSEON 建立使用者的「認知指紋」：擅長的思考路徑、常用的決策框架、對模糊資訊的反應模式。每次互動都在更新這張圖譜。

PERSONA ENGINE
⚙️

思維方法論結晶

當使用者重複使用某個分析框架，MUSEON 會主動結晶為「可調用規則」。下次遇到類似問題，MUSEON 優先套用已驗證的使用者框架，而非通用模板。

CRYSTAL ACTUATOR
📋

審計能力存檔

使用者做決策的標準（什麼叫「夠好」、什麼叫「不行」）被記錄為審計規則。MUSEON 輸出內容時會自動對照，產出符合使用者標準的結果。

AUDIT STANDARD
🔄

工作流沉澱

重複執行的任務序列自動固化為 Skill 工作流。使用者不需要每次下指令，MUSEON 識別情境後主動調用。工作流越用越精準。

SKILL CRYSTALLIZE

1-b｜預判同事接受度

因為每位同事都有獨立的互動群組，MUSEON 累積了各自的「反應模式」——面對變革提案，誰是早期採用者、誰需要數據佐證、誰會抗拒到最後。在推動內部決策前，MUSEON 可以模擬「這個政策丟出去，各部門的第一反應是什麼」。

1-c｜預判商務談判情境

MUSEON 記錄了客戶每次互動的語言模式、關注點、讓步信號。下次談判前，MUSEON 可以推演：「根據上次的互動，他在價格上最可能接受的區間是 X，他最在意的不是折扣而是交期保證。」

1-d｜任務分派與外部槓桿

MUSEON 知道每個團隊成員的能力圖譜，在提出策略時，同步輸出「誰負責哪個環節」的分派建議。在引入外部合作夥伴時，MUSEON 根據對方的業務脈絡自動生成談判重點，縮短協商時間，降低溝通成本。

獨特價值：越用越懂你

SaaS 工具第 1 天和第 365 天的體驗相同。MUSEON 第 1 天是通用模板，第 365 天是「你的分身」。它的建議會帶著你的語氣、你的判斷標準、你過去說過的話——這是任何工具型 AI 無法複製的護城河。

02

MuseMEM × Persona × ANIMA
三核心如何塑造獨特性

三個系統不是獨立模組，是交叉作用的生態系——缺一不可。

CORE 01 · 記憶層

MuseMEM

向量記憶引擎。把對話、決策、偏好轉化為可語意搜尋的記憶節點，而非線性日誌。

  • 跨對話脈絡保留
  • 語意相似度召回
  • 記憶分層（短期 / 長期 / 結晶）
  • 使用者 × 客戶分別建庫
CORE 02 · 人格層

Persona

使用者的認知圖譜。記錄決策風格、溝通偏好、八原語能量分佈，讓回應有「對象感」。

  • One Muse 人格四軸線
  • 業務脈絡動態更新
  • 針對不同使用者切換輸出風格
  • 判斷「什麼時候建議、什麼時候等」
CORE 03 · 情感層

ANIMA

MUSEON 的情感感知引擎。偵測使用者當前能量狀態，調整互動節奏和建議深度。

  • 六大盲區動態追蹤
  • 七武海能量維度感知
  • 情緒狀態調節輸出風格
  • 建立長期信任關係的節奏感

三者交叉的核心威力

當 MuseMEM 搜尋到「上次客戶說過很在意交期」（記憶）+ Persona 判斷「這個使用者習慣直接給結論不要廢話」（人格）+ ANIMA 感知「今天使用者能量偏低，決策需要更簡化」（情感）——

MUSEON 輸出的不是「答案」，而是「在對的時機、以對的語氣、說這個人聽得進去的話」。

2-a｜MUSEON 的自動化能力

Nightly Pipeline 每日自動執行：晨報生成、記憶結晶、健康診斷、探索報告。定時推播使用者狀態摘要。這些是 MUSEON 的「呼吸」——不需要使用者觸發。

AUTONOMOUS BREATHING
🔧

2-b｜工具能力的邊界

MUSEON 有 MCP tools、shell_exec、web_search 等工具，但不是以工具廣度為核心競爭力。它用工具是為了「讓建議落地」，不是為了「替代 RPA 或 ETL 流水線」。

TOOL AS SUPPLEMENT
🎯

2-c｜未來：MUSEON 統籌 Agent 團隊

MUSEON 作為認知中樞，判斷「什麼任務交給哪個工具型 Agent」。OpenClaw 執行資料爬取，MUSEON 解讀結果做策略建議。這是「首席顧問 + 執行團隊」的分工。

5 種內部工作流

中小企業內部使用場景——讓組織知識不再隨人員流動消失。

I-1

知識傳承 × 新人快速上手

資深員工的判斷邏輯透過對話結晶，轉化為「新人 SOP + 常見問題庫」。新人向 MUSEON 提問，得到的是前輩的思維方式，而非通用回答。

資深員工與 MUSEON 對話 30 天 → 建立認知圖譜
→
常見情境問答自動結晶為 Skill
→
新人提問 → MUSEON 用前輩框架回答 + 標示「這是誰的判斷」
MuseMEM knowledge-lattice meta-learning
I-2

決策審計 × 品質標準維持

老闆的審計標準被記錄為規則。員工提案時，MUSEON 先比對老闆過去說過的「這樣不行」，自動標記不符合標準的環節，節省老闆 review 時間。

老闆與 MUSEON 對話 → 審計標準結晶
→
員工提案上傳 → MUSEON 自動審計 + 標記風險點
→
老闆只看「已標記的爭議點」，決策時間縮短 60%
qa-auditor decision-tracker Persona
I-3

會議情報 × 行動追蹤

會議錄音 → 逐字稿 → MUSEON 自動提取決策事項、責任人、截止日。下次會議前主動提醒「上次說的 X 還沒完成」，讓會議結論真正落地。

錄音上傳 → 逐字稿生成
→
MUSEON 提取：決策 / 待辦 / 責任人 / 截止
→
Nightly 追蹤未完成項目 → Telegram 推播提醒
meeting-intelligence group-meeting-notes daily-pilot
I-4

團隊人格圖譜 × 任務分派優化

每個成員的 Persona 累積後，老闆在討論新任務時，MUSEON 自動推薦「這件事最適合誰做」——不只看職位，也看個性與能量狀態。

各成員 Telegram 群組互動 → Persona 圖譜建立
→
老闆描述新任務 → MUSEON 輸出「分派建議 + 風險提示」
→
降低分工錯誤、減少「明明不適合但被指派」的情況
talent-match anima-individual Persona
I-5

二代接班 × 創辦人認知傳承系統

最難被複製的不是流程，是創辦人「憑感覺就知道哪裡不對」的判斷力。MUSEON 透過長期記錄，把這個「感覺」具體化為可被接班人查詢、學習的認知資產庫。

創辦人日常決策、對話 → MuseMEM 累積
→
關鍵判斷自動結晶 → 附「為什麼這樣判斷」的脈絡
→
接班人遇到類似情境 → MUSEON 召回「創辦人當年怎麼看這件事」
→
傳承的不是 SOP，是判斷力
MuseMEM knowledge-lattice succession-architecture ANIMA

5 種外部工作流

業務拓展、客戶關係、市場情報——讓 MUSEON 成為業務戰力的乘數。

E-1

客戶諮詢 × 人格分析 × 精準提案

一對一諮詢錄音 → 逐字稿 → MUSEON 生成客戶人格圖譜 + 痛點精確定位 + 第一步提案句。業務從「展示功能」升級為「提供解法」。

諮詢 30-60 分鐘 + 錄音
→
MUSEON：人格報告 + 三大痛點 + 提案語句
→
當場或 24 小時內發送「你的專屬報告」給潛在客戶
onemuse-core seven-steps-to-insight client-onboarding
E-2

競品監控 × 市場情報自動摘要

定期自動爬取競品動態、行業新聞，MUSEON 過濾雜訊，只推送「跟你的業務決策有關的」訊息，並附帶「你可以這樣應對」的建議。

Nightly 自動抓取市場訊號
→
MUSEON 過濾：只留「與你相關的 10%」
→
早晨推送：3 條情報 + 各自的應對建議
market-core sentiment-radar env-radar
E-3

提案書 × 報告自動生成

顧問描述客戶背景，MUSEON 生成產業級診斷報告——包含數據視覺化、風險矩陣、三年路線圖。從「我來寫」變成「我來確認和調整」。

顧問輸入：客戶行業 / 痛點 / 目標
→
MUSEON 生成完整 HTML 報告（含品牌規範）
→
顧問 review → 一鍵發布 GitHub Pages 連結給客戶
report-forge biz-diagnostic brand-builder
E-4

商務談判 × 策略預演

談判前，MUSEON 調用對方的 Ares 人物檔案，生成「戰前簡報」：對方的決策模式、讓步底線推測、最有效的開場策略、要避開的雷區。

輸入：我方目標 + 對方名稱
→
MUSEON 生成戰前簡報（人格 + 策略 + 問題模板）
→
談判後更新：哪個策略有效、哪個無效 → 下次更準
master-strategy shadow ares_briefing
E-5

異業合作媒合 × 外部槓桿自動盤點

當老闆說「我想擴展 XX 市場」，MUSEON 不只給市場分析——它掃描人脈庫，找出「誰的資源可以被槓桿」，生成「合作腳本 + 利益交換架構 + 切入信」。把人脈從通訊錄升級為槓桿地圖。

老闆描述擴展目標
→
MUSEON 掃描 Ares 人物庫 → 找出相關節點 + 槓桿路徑
→
生成：潛在合作夥伴名單 + 各自的利益交換方案
→
自動草擬切入信（對方語言風格 + 我方最強賣點）
biz-collab athena ssa-consultant ares_topology
