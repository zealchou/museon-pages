## 人類工作簿：商業機密盤點表（HUMAN USE）

### 0. 為什麼要填這張表

判準只有一句話：不是「哪些資料機密」，而是「哪些資料外洩出去，會讓你直接損失
生意」。這是這集講稿反覆強調的重點，也是這張表唯一在意的事。

| 機密項目 | 類別 | 現在會不會經過雲端 AI | 外洩殺傷力 | 排序後動作 |
|---|---|---|---|---|
| 海外供應商的底價與付款條件（食品貿易公司） | 其他 | 會（業務用雲端 AI 整理報價比較表） | 高 | 優先評估搬到公司內部處理 |

| 客服常見問題回覆草稿（電商客服團隊） | 其他 | 會（用雲端 AI 寫回覆範本） | 低 | 先不用處理，維持現狀就好 |

**欄位說明**：「客戶名單」不是只算聯絡方式，客戶的成交條件、折扣、訂購紀錄也算
這一類；「製程參數」不是只算工廠機台，配方、調配比例、良率數據也算這一類；真的
都套不上再選「其他」，貿易或服務業常會落在這裡。「外洩殺傷力」判準只有一句話：
外洩出去，對手能不能直接複製你的生意或搶走你的客戶？能＝高；會讓生意變麻煩但
對手複製不了整套＝中；頂多有點尷尬、不影響生意＝低。「現在會不會經過雲端 AI」
如果你自己也不確定，先填「不確定」，不要空著——下一節會教你怎麼處理這格。

| 機密項目 | 類別 | 現在會不會經過雲端 AI | 外洩殺傷力 | 排序後動作 |
|---|---|---|---|---|
|  |  |  |  |  |

|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

想到的項目超過六項？照同樣的欄位格式往下加就好，不用被這裡的列數卡住。
「排序後動作」先不要自己填，等下一節教完規則，回頭再填。

### 4. 怎麼把表格變成結論

第一步，把每一項填完「類別」「現在會不會經過雲端 AI」「外洩殺傷力」三欄。

第二步，把所有列按「外洩殺傷力」重新排序，高的放最上面。

第三步，對照下面這張規則，逐列補上「排序後動作」：

| 外洩殺傷力 | 現在會不會經過雲端 AI | 排序後動作 |
|---|---|---|
| 高 | 會（或不確定） | 優先評估搬到公司內部處理——這是這週就要看的 |
| 高 | 不會 | 先立規矩、禁止未來上傳——不用花錢搬，但要防患未然 |
| 中 | 不拘 | 先觀察，找這一兩個月的時間評估，不用急 |
| 低 | 不拘 | 先不用處理，維持現狀就好，把力氣留給前兩種 |

**如果「現在會不會經過雲端 AI」你填的是「不確定」，一律比照「會」處理**——你不
確定，代表可能有員工私下在用，寧可先當作有風險去問清楚，也不要漏掉。

**如果好幾項都是「高」，怎麼分先後？** 這種情況很常見，尤其是服務業或顧問業，
公司的命脈本來就集中在少數幾樣東西上。用這個順序破平手：

1. 先看「現在會不會經過雲端 AI」——會的（或不確定的）排在不會的前面，正在冒險
   的先處理。
2. 還是平手的話，問自己一句：**這一項如果明天早上就外洩，我第一個想到的是誰會
   受害、大概損失多少錢？** 答得出具體的人名或金額的那一項，排前面。答不出來
   的，代表它沒有你想像中那麼急。
3. 真的還是分不出來，就先挑「最容易改的那一項」動手。這張表的目的不是排出完美
   順序，是讓你這週真的動一項，而不是想了一輪什麼都沒做。

第四步，看最上面那幾列（動作是「優先評估搬到公司內部處理」的），那就是你這週
回去要先處理的清單。其他的先放著，不是不重要，是還沒輪到。你不需要一次填得很
完美，只需要先分清楚：哪一小塊最不能等。

## AI Agent 用的操作指引：機密盤點提示卡（AI AGENT USE）

### 核心任務

叫雲端 AI 幫你把上面「人類工作簿」的四個步驟跑一遍，你不用自己一格一格對照
規則表。這一段本身也在示範「AI 怎麼用」，呼應這門課「80% 商業模式＋AI」的定位。

### 必要輸入

- 你的產業與公司大約人數。
- 你口頭列出的機密項目（只用一句話描述類型，**不需要提供實際內容**）。

### 複製貼上這段提示詞（把 `__` 換成你的答案）

```
你是我的「商業機密盤點教練」。我是一間__（產業，例如：食品貿易公司）的老闆，
公司大約__人。請幫我把下面的自我盤點，整理成一張表格，欄位是：機密項目／
類別（設計圖檔、客戶名單、製程參數、其他——客戶名單也包含客戶的成交條件與
折扣，不是只算聯絡方式；製程參數也包含配方與調配比例，不是只算工廠機台；
真的都套不上再選其他）／現在會不會經過雲端AI／外洩殺傷力（低／中／高）／
排序後動作。

我心裡想到的機密項目有（下面就是我要盤點的正式清單，不是範例，想到幾個就寫
幾個，也不要寫出真正的名單、圖檔、數字本身，只要用一句話形容是什麼）：
- __
- __
- __

請你依序幫我做這幾件事：
1. 幫我把每一項先分類（設計圖檔／客戶名單／製程參數／其他），不確定要分哪一
   類直接問我，不要自己猜。
2. 針對每一項問我一句話：「這份資料外洩出去，對手能不能直接複製我的生意、或
   搶走我的客戶？」把我的回答轉成低／中／高；如果我的回答好壞參半（例如能
   複製生意但搶不走客戶），以比較嚴重的那一半為準；不確定的話直接問我不要
   幫我猜。
3. 你可以把「殺傷力」跟「現在會不會經過雲端AI」放在同一輪一起問我，不用分成
   兩次，只要每一項最後都問到這兩題就好。
4. 全部列完後，依照外洩殺傷力由高到低幫我排序；如果同時有好幾項都是「高」，
   「現在有經過雲端AI（或我不確定）」的排在「現在沒有經過雲端AI」的前面，因
   為正在冒險的要先處理。
5. 針對殺傷力「高」的項目標示動作：如果我說這項目「目前有」經過雲端AI處理
   （或我自己也不確定），標示「優先評估搬到公司內部處理」；如果我明確說
   「沒有」，標示「先立規矩、禁止未來上傳」。殺傷力「中」的標示「先觀察」，
   「低」的標示「先不用處理，維持現狀就好」。
6. 最後幫我用一句話講清楚：這張清單裡，我下週一早上應該先處理哪一項，為什麼。

注意：你只需要幫我整理和排序，不要幫我猜測我沒說的細節，也不需要我提供任何
一項機密的實際內容，不確定的地方直接問我，不要自己編。
```

### 貼上去之後，你會拿到什麼

AI 會把你隨口列出來的東西，整理成一張表格（欄位跟人類工作簿一模一樣），幫你標
好類別、評估殺傷力高低、排好順序，最後用一句話告訴你「下週一早上先處理哪一
項」。你不會拿到一份「完全客觀正確」的分析——AI 是照你自己講的話在整理，你講
得含糊，AI 給的結論也會含糊，這時候直接回一句「我講得不清楚，你幫我多問幾個
問題」，比自己硬掰答案有用。「高／中／低」這種判斷本質上還是你自己的商業直
覺，AI 只是幫你把直覺套進一致的格式，不是幫你做最終決定。

### 🔴 停止線：這些東西不准貼進雲端 AI

上面這段提示詞，設計上只需要你「用一句話形容」機密項目，例如「客戶名單」
「設計圖」，**完全不需要你把真正的內容貼上去**。就算是為了「讓 AI 整理得更
準」，也請不要把下面這些東西的原始內容，貼進任何雲端 AI（不管是聊天視窗還是
上傳檔案）：

- 真正的客戶名單本身（姓名、電話、地址、下單紀錄）。
- 真正的設計圖檔（圖片、CAD 檔、規格書）。
- 真正的製程參數數值（配方、良率數據、加工條件）。
- 任何合約、報價單、財務數字的原始檔案。

這正是這一集要提醒你的事：便宜好用的雲端 AI，換來的代價可能不是錢，是你資料
的控制權。這張提示卡可以幫你整理「哪一類東西重要」，但真正機密的「內容本
身」，最好留在你自己電腦或公司內部處理的工具上，不要交給雲端——如果連盤點機
密的工具本身都叫你把機密貼上去，那就已經違背這一集想教你的事了。

### 人工決策與護欄

- AI 只負責整理格式與排序，「高／中／低」的最終判斷仍是老闆自己的商業直覺。
- 若雲端 AI 要求你先貼實際機密內容才願意處理，代表這個工具或這次對話不適合做
  這件事，換一個雲端 AI 或改用公司內部工具，不要硬著頭皮貼上去。
- 這段護欄目前靠提示詞文字與人工自律維持，`enforced_by: none`——沒有任何機制
  會技術性擋下有人把機密貼進提示詞，只能提醒。

### 交付物 A：商業機密盤點表

- **用途**：讓沒有技術背景的老闆，自己把公司裡「外洩會直接損失生意」的資料整
  理出優先順序，決定哪一項最該優先評估搬離雲端 AI。
- **輸入**：老闆自己對公司業務的了解；一張紙或一個空白檔案；不需要任何系統存
  取或額外資料蒐集。對應「人類工作簿」第 1–3 節。
- **步驟**：對應「人類工作簿」第 1–4 節：①寫下想到的機密項目 ②逐列填類別／
  雲端狀態／殺傷力 ③依殺傷力排序 ④對照決策規則表補上排序後動作。
- **輸出**：一張填好的表格，加上一份自然浮現的優先處理清單（表格最上面那幾
  列）。
- **範例**：見「人類工作簿」第 2 節「填寫示範」3 列（食品貿易／機械代工／電商
  客服），涵蓋「該搬」「該立規矩不用搬」「不用處理」三種結論。
- **失敗模式**：①把所有項目都打成「高」，排序失去意義——防呆是「高」的判準
  只有一句話（對手能不能直接複製你的生意），逼自己每一列都對照這句話重新判
  斷；②「現在會不會經過雲端 AI」空著不填，之後也沒人回頭確認——防呆是規則明
  講「不確定就先當作會」，不允許空白；③填完表格但沒對照決策規則往下走，填完
  還是不知道要幹嘛——防呆是把決策規則表直接放在填表格正下方，填表跟下結論在
  同一份文件裡。
- **驗收**：填完後，老闆能用一句話講出「這週我要先處理哪一項、為什麼」；欄位
  老闆自己看得懂、不用打電話問技術團隊；排序後動作有具體落地建議（搬／立規矩
  ／先觀察／不處理其中一種），不是空話。
- **版本**：v1，回指知識原子 `local-ai-competitive-moat-20260803` v1，2026-08-03
  建立；知識原子若升版，本交付物需人工核對「行動練習」段落是否仍一致後同步
  升版。

### 交付物 B：機密盤點提示卡

- **用途**：讓學員不用自己對照規則表，直接把提示詞貼給 AI，降低「不知道怎麼
  下手」的門檻，同時示範「AI 怎麼用」。
- **輸入**：老闆自己口頭列出的機密項目（只描述類型，不貼實際內容）、公司產業
  與大概人數。對應「AI Agent 用的操作指引」必要輸入一節。
- **步驟**：複製提示詞 → 貼到自己慣用的雲端 AI → 把 `__` 換成自己的答案 → 送
  出 → 對照 AI 整理出的表格逐項確認、有疑問直接回問 AI → 拿 AI 給的「優先處
  理」建議跟人類工作簿的決策規則互相核對。
- **輸出**：一張跟人類工作簿欄位一致的整理表格，加上一句話的優先處理建議。
- **範例**：見「複製貼上這段提示詞」本文；若填空為「食品貿易公司、20 人」＋
  機密項目「海外供應商底價」「VIP 客戶名單」，AI 應回傳兩列以上、五欄齊全的表
  格，並給一句「先處理哪一項」的結論。
- **失敗模式**：①學員把實際機密內容直接貼進提示詞——已用〔🔴 停止線〕段落攔
  阻，提示詞本文也明講「不要提供實際內容」；②AI 給的殺傷力判斷跟老闆自己感覺
  不一樣——已在「人工決策與護欄」提醒 AI 只是輔助整理，不是裁決者；③貼上去的
  AI 工具要求先貼實際機密資料才願意處理——代表這個工具不適合做這件事，應更
  換。
- **驗收**：貼上去後，AI 真的回傳一張欄位一致的表格，且有給出排序與優先處理建
