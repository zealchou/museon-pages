兩項關鍵判定

1. Easegen 的 PPT 講解設計文件：成立，但只成立為「流程設計」

指定檔案確實位於 easegen-front 的 main/easegen-3d-lecture-system/docs/。它定義 PPTLecturePlayer 協調 EaseGen、Fay、Xmov：從 EaseGen API 取得課程片段與投影片資料，前端先準備投影片；Fay 輸出 TTS 後，前端以文字摘要判定是否顯示該頁，並把內容送進 Xmov SDK。語音結束後再要求下一片段。

判定：原報告將此濃縮為「取得下一段文字與投影片圖 → TTS → 顯示該頁 → 數位人說話」，轉述正確；但文件本身是「實現方案」，不可單獨當成已部署、可直接安裝或已具備本機聲音克隆的證據。

2. HeyGen 與 DeepBrain：成立為同產品中的雲端一站式流程

HeyGen 的 PPT/PDF 文件將 PPT 匯入、逐張 script segment、換旁白與 MP4 匯出置於 AI Studio 流程；Voice 文件則說可在 AI Studio 建立 Instant Voice Cloning，並在 avatar video 或 script 編輯時選用。DeepBrain AI Studios 的 PPT 文件則說每頁成為 individual video scene；其 Voice Clone 文件說 clone 可由 video editor 建立，並出現在所有影片專案的 AI Voice 選單。

判定：兩者足以支持「商業雲端一站式」這個限定結論。官方頁面沒有保證特定語言品質、方案額度或每頁講稿一定全自動正確；它們也不是本機／自架方案。
