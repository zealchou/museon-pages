Sprint 短衝三力
立即見效的槓桿
BF01 · 產品力
多系統命理融合報告
8.0
最強護城河：N 套命理系統並列計算（紫微/八字/易經/人類圖等）→ 融合 Skill → 口吻 Skill → 排版 Skill，形成競爭者難以複製的技術壁壘。現有問題：工作流三個 Skill 都是「順手做」的草稿，準度和體驗未達「哇靠超準」的觸發門檻。
行動：「三件事認真調整」——描述口吻 Skill + 報告模板 + 報告呈現 Skill。這三個升級直接決定 BF02 累積力能否啟動。
BF11 · 談判力
定價策略 + 海軍成交設計
7.5
NT$1,000 在命理消費帶（500-3,000 元）屬低門檻進場，加上分潤結構清楚（L1 30% / L2 15%）。海軍節點給「命理技術不上不下的人」出路，是雙贏設計。弱點：尚無快速成交語言——海軍節點面對客戶時沒有標準話術。
補強：為海軍準備 3 句話成交腳本。「你現在算命的準度能達到幾成？我們這個是 N 個千年系統交叉驗證，結果指向同一個你。」
BF12 · 轉換力
QR 碼 + 圖卡裂變漏斗
7.0
圖卡 + QR 碼讓「社交貨幣」直接觸達陌生人，是聰明的入口設計。卡點：系統尚未穩定（Alan 修復中），掃碼後 Landing 頁的 30 秒轉換體驗尚未設計。
設計：掃碼後的 Landing 頁，讓「為什麼要買」的答案在 30 秒內清楚。核心信息：這不是算命，這是 N 個系統同時指向你的自我洞察。
Sustain 穩抗三力
穩定抗跌的護城河
BF04 · 共享力
分潤裂變 + 海軍聯盟
9.0
本商模最強設計。兩層分潤（30%+15%）+ 圖卡 QR 碼 + 海軍作為節點三個共享機制同時運作。海軍節點特別聰明：他們理解產品、有成交動機、有既有人脈——說服力遠超純傭金推廣者。
進一步強化：海軍月 KPI（每人每月 ≥5 份）+ 海軍排行榜。讓競爭感與歸屬感並存，防止節點沉寂。
BF06 · 感召力
品牌故事 + 情感價值主張
5.5
目前尚無清楚的感召語言。產品核心是「多系統交叉驗證的自我洞察」，但這句話用戶聽不懂也感受不到。感召力是把「功能」轉化為「我需要它」的橋樑。
需要一句話定位：「你從來沒有同時被 N 個千年系統指向同一個你的樣子。」——讓用戶感受到稀有感與啟示感，而非「又一個算命服務」。
BF09 · 社群力
海軍聯盟 + 墨客社群
8.0
Zeal 的核心優勢：有既有社群（海軍 + 墨客學生），不是從零開始裂變。第一輪 100 人裂變是真實可行的，而不是理論假設。社群力的關鍵：讓分享行為有儀式感，「曬報告」成為群體認同的表達。
設計社群內「圖卡分享挑戰」——分享圖卡並 tag 一個朋友，觸發社群自主傳播。SSA 鐵粉三層晉級：滿意客戶 → 忠誠客戶 → 鐵粉大使。
Nurture 長養三力
長期複利的資產
BF03 · 整合力
多系統融合 + 跨平台整合
8.5
Zeal 擁有多系統命理融合的方法論（真正的稀缺資產），Alan 提供技術整合，MUSEON 作為智能腦——三者分工清晰且各有不可替代性。未來整合 OneMuse / 墨客生態潛力巨大。
長期護城河策略：將融合方法論「標準化」成可授權的技術規格，防止仿製。「系統」是壁壘，不只是「服務」。
BF07 · 品牌力
品牌定位 + 人格語調
5.0
這個產品還沒有獨立的品牌人格。面向終端用戶的品牌是空白——口碑傳播現在依賴「人」（海軍節點）而不是「品牌」。規模化後，這個依賴會成為天花板。
產品需要一個名字和一個核心定位語。方向：「多維命理交叉洞察系統」類型——讓人一聽就知道這不是普通算命，而是系統級的自我認識工具。
BF08 · 優化力
KPI 追蹤 + 持續改善
6.0
目前系統仍在開發迭代中，缺少的是：報告準度追蹤（哪些系統命中率最高？）、裂變轉換率（哪個節點最有效？）、用戶回購率數據。優化力是把「感覺不錯」變成「可測量地好」的能力。
建立三個最小追蹤指標：報告好評率 / 圖卡掃碼轉換率 / 海軍節點月均推出份數。這三個數字足以驅動所有後續決策。
Base 底盤三力
所有力的基礎——底盤不穩，上層力折損
BF02 · 累積力
案例 + 見證 + 可複用資產
4.0
最急底盤缺口。 沒有案例就沒有說服力，裂變只靠節點個人信用。SSA 口碑先行原則：沒有 90% 好評率，不大規模裂變。第一批 10-20 份報告的真實用戶反饋是最急迫的資產。
行動：從海軍節點自己先用，收集第一批「哇靠超準」截圖素材庫。這是整個口碑裂變飛輪的燃料，沒有它飛輪不會轉。
BF05 · 感受力
用戶旅程 + WOW 時刻設計
6.5
報告必須在用戶拿到瞬間觸發「哇靠超準」感受——這個感受是裂變動機的觸發點。SSA 七步逆向工程：從「拿到報告後第一件事是分享圖卡」往前倒推每一步體驗設計。
WOW 時刻設計：第一頁就要出現讓人感到「這說中了我獨特的某個點」的個人化洞察，而不是泛泛通論。個人化深度 = 分享動機強度。
BF10 · 視覺力
圖卡設計 + 報告視覺
4.0
與累積力並列最急底盤缺口。 Zeal 自評：「報告的模板是之前隨便做的，報告呈現的 Skill 也是昨天順手做的。」視覺力決定圖卡是否值得分享——在 IG 時代，視覺品質直接等於社交貨幣的面額。草稿視覺 = 廉價社交貨幣 = 沒人分享。
升級目標：達到「可以直接出現在朋友圈不丟臉」的標準。參考 16Personalities 圖卡——乾淨、有設計感、一眼讀懂自己的特質。

Founder-Market Fit 診斷
命中度：極高（9/10）

Zeal 同時掌握：（1）命理方法論的原創融合能力，（2）有意願有能力的技術夥伴（Alan），（3）既有分發節點（海軍 + 墨客社群），（4）MUSEON 作為底層智能腦。

這四個條件同時具備的創業者，在台灣命理 AI 市場裡是極少數。市場時機也準確：AI 準度已讓「命理 + 科技」組合脫離偽科學框架，進入可信的消費體驗區間。
⚡
八大槓桿識別與排序
當前最高槓桿排序：

1. 知識槓桿（最高）——多系統融合方法論是不可複製的核心資產，必須標準化並保護。這是競爭壁壘的本質。

2. 人脈槓桿——海軍節點是現成的高信任分發渠道，比任何廣告都便宜且有效。

3. 平台槓桿——MUSEON 作為可擴展技術底座，邊際成本極低，是核心成本競爭力。

4. 品牌槓桿——口碑飛輪一旦啟動，品牌自然沉澱。目前尚未啟動（BF07 品牌力 5.0）。
🔄
口碑先行 × 鐵粉裂變設計
SSA 鐵律：沒有 90% 好評率，不大規模裂變。

當前口碑飛輪啟動評估：
  • 準度：Alan 修復中，穩定基準未確立
  • 視覺：草稿狀態（BF10 4.0），需升級
  • 體驗：WOW 時刻設計尚未完成（BF05 6.5）
  • 案例：第一批見證素材零（BF02 4.0）

結論：飛輪啟動條件尚未就位。現在起跑大規模裂變，負口碑傳播速度與裂變速度一樣快。

裂變率低於假設（BF12 BF04）

緩解：設計容量預警機制，有序排隊而非降質。用等待感製造稀缺感（「目前排隊 XXX 人」）。
