人像處理：主案是真去背，不是大面積羽化

  1. 從原西裝照建立一張衍生 alpha 遮罩。這不是生成新人物，只是把既有照片的背景拿掉。遮罩應人工精修頭髮、耳朵、肩線與交叉手臂，不用藍幕色差硬猜，因為西裝本身也是灰藍色。
  2. 邊緣只做 1.5–2px 羽化。這個數值用來消鋸齒，不是做光暈；禁止 20px 以上的全身模糊邊。
  3. 整體調色而非局部塗臉。建議 Color=0.78、Contrast=0.96、Brightness=1.02，降低攝影棚冷藍與紙面衝突，臉部像素本身不重畫。
  4. 不加外框與明顯投影。身體下緣直接沉入底圖右下水墨；若輪廓仍浮，只允許肩部以下做 8–12% 墨色、14px blur 的接地陰影，臉與頭髮後方不得有光圈。
Plan B：若這一輪無法取得精修遮罩，可以用現成透明光頭照先做內部預覽，但它的橘外套與近距離自拍感會把品牌拉向生活型個人頻道，不建議直接上線。四邊羽化的西裝方框也只准當內部比較稿。

以下不是完整施工碼，而是把設計決策固定成可直接接到現有腳本的圖層順序。唯一需要先準備的是同一張西裝照的精修 alpha 遮罩。

from pathlib import Path
from PIL import Image, ImageDraw, ImageEnhance, ImageFilter, ImageOps

W, H = 2560, 1440

img = Image.open(WASH_03).convert("RGB")

# PHOTO_CUTOUT 是原西裝照的衍生去背檔，不是生成新人物
person = Image.open(PHOTO_CUTOUT).convert("RGBA")
person = person.crop((80, 50, 980, 1080))
person = ImageOps.contain(person, (664, 760), Image.Resampling.LANCZOS)
rgb = ImageEnhance.Color(person.convert("RGB")).enhance(0.78)
rgb = ImageEnhance.Contrast(rgb).enhance(0.96)
rgb = ImageEnhance.Brightness(rgb).enhance(1.02)
rgb.putalpha(person.getchannel("A").filter(ImageFilter.GaussianBlur(1.8)))
img.paste(rgb, (1360, 470), rgb)
