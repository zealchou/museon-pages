①内容製作：現在做到哪

依 docs/BLUEPRINT_v1.md 的 M1～M9 設計，四講（成本／價值／價格走廊／因果報價）都已完整走過一輪：投影片轉圖 → 逐字稿（先擴寫到 15 分鐘以上，Zeal 現場給過三則具體回饋，逐頁配術語白話解釋）→ Zeal 人工核准 → 用他本人的克隆聲音逐頁合成 → 依實際音長組裝成 MP4 → 技術檢查通過後放行。

②YouTube 上架配套：現在做到哪

四支影片（Q1～Q4）都已上傳，各自有字幕、說明欄（仿 Gary Chen 頻道的「痛點→時間戳→CTA」結構）、分類與播放清單。縮圖這條線這次 session 走了三輪修正：先發現實作跟已核准的規格有落差（混了水彩、人像壓字）→ 改回規格 → 上傳 → Zeal 看了真實頻道畫面覺得那條朱砂分隔線突兀 → 拿掉重傳，目前四張已是最新版本。

缺口狀態備註
字幕語言標籤誤標 en（內容其實是中文） 待處理 兩種 API 修法都試過並失敗，只能 Zeal 到 YouTube Studio 網頁手動刪除重傳。
GPU smoke test 腳本不支援純離線本機路徑 待處理 不影響現況，機器目前連得到網，留給未來要支援離線部署時再補。
語速校正值曾用合成占位聲音算 已解決 已用 Zeal 真人錄音重算，兩次差異僅 2.7%，不影響任何已核准逐字稿。

③人像視覺素材：一條還沒正式接上的支線

這是這次 session 花最多力氣的部分，但目前還沒有任何正式縮圖或影片用到它——現有四張縮圖用的是 Zeal 既有的一張職業照，不是 LoRA 生成的臉。訓練照片從 27 張篩到 37 張，模型跑了 v1 到 v5 五輪，v4 的眼睛、v5 的鼻子嘴巴各有優勢，也試過把兩版權重各半融合，結果比較像 v5、沒有明顯保留 v4 的特質。Zeal 的結論是「沒差，先這樣吧」——這條線目前收斂在這裡，之後若要正式用在縮圖或影片素材上，需要再重新啟動。
