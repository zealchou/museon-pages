SSA 系統創業加速分析

SSA（系統創業加速）框架從三個層次評估創業系統成熟度：信念/定位層 → 產品/服務層 → 銷售/槓桿層。三層對齊才能形成自我加速飛輪。

Layer 1 · 已完成
信念 × 定位層 ── 北極星清晰
核心信念已固化：「AI 讓人類圖普及化，以百分之一的成本提供高端命理洞察。」 定位清晰，市場空白明確，目標族群有強烈心理驅動力。
  • ✓ Why：讓命理不再只是少數人能負擔的奢侈品
  • ✓ Who：25-45 歲，自我探索，願意為自我認知付費
  • ✓ What：AI 多系統融合，準確感知優於單一系統
  • ✓ 競爭護城：技術壁壘 + 社群口碑，非價格競爭
Layer 2 · 進行中
產品 × 服務層 ── 核心品質 70%
技術架構已定（多 agent 並行 + cache 優化），但決定使用者第一印象的三個 skill 仍在調優中。這三件事直接影響「準確感知」，是啟動裂變飛輪的臨界點。
  • ✓ 多 agent 並行計算架構完成
  • ✓ Claude API cache write 成本優化（NT$3/份）
  • ✓ Agent 防護機制建立（防止跨 agent 污染）
  • ◐ 口吻 skill——命理描述語言調優（臨時版需重建）
  • ◐ 融合 skill——N 套命理結論整合邏輯
  • ◐ 排版 skill——HTML 報告視覺品質升級
🎯
Layer 2 關鍵指令：Zeal 說「隨便玩跟認真當專業事業做還是不一樣的」——口吻×融合×排版三 skill 認真升級是通往裂變的唯一入口，也是 Layer 2 對齊 Layer 1 信念的必要條件。
Layer 3 · 待激活
銷售 × 槓桿層 ── 系統已設計，飛輪未啟動
雙層分潤（30%+15%）機制已設計，但飛輪尚未啟動。Layer 3 的關鍵是「第一批種子推廣者是否拿到足夠準的產品願意全力推廣」——Layer 2 品質是 Layer 3 的前提。
  • ○ 種子推廣者招募（人類圖社群 KOL × 3-5 人）
  • ○ 分潤後台系統（追蹤鏈接、結算、儀表板）
  • ○ 推廣者工具包（話術、視覺素材）
  • ○ 首批 100 份免費報告（種子口碑種植）
  • ○ 社群曝光策略（FB 人類圖社團、Dcard 星座版）
SSA 仲裁結論
系統當前處於 Layer 2 品質臨界點。Layer 1 強勢，Layer 3 機制就緒待激活。唯一制約是 Layer 2 的口吻×融合×排版品質。建議集中 2-3 週全力升級這三個 skill，品質到位即立刻啟動 Layer 3 種子推廣者計畫。

九策軍師圓桌會議

九位虛擬軍師，各持一策，從不同視角對 humanhd 的戰略路徑提出建議與警示。

策一
🗡️ 速攻策 — 快刀斬亂麻
不要等系統完美再推。人類圖社群核心用戶先發免費報告，收集「超準」截圖，形成口碑彈藥。速攻的目的不是賺錢，是製造彈藥庫。
立即行動：徵召種子測試者 30 人，收截圖授權
策二
🏯 圍城策 — 讓別人幫你打城
雙層分潤機制本質是圍城策——讓推廣者有切身利益守護城池。第一層 30% 遠高市場平均（通常 10-20%），足以讓社群版主全力推廣而非隨手分享。
關鍵設計：推廣者儀表板即時顯示收益
策三
🌊 借勢策 — 站在浪頭上
全球占星 App 市場 CAGR 20%，亞太 AI × 命理融合尚無清晰領導者。2026-2027 是建立品類領導者的黃金視窗，等市場成熟再進，定位成本指數級上升。
PR 方向：「台灣第一個 AI 多系統命理融合平台」
策四
⚔️ 分化策 — 讓競爭者顯得落伍
強調「AI 融合 N 套命理系統」vs 競爭者「單一系統報告」。命理消費者懂差異——多系統融合讓 humanhd 自動成為「更全面」的選擇。
教育行銷：「為何單一人類圖不夠用？」內容系列
策五
🪤 引蛇策 — 低門檻進場，高溫度留存
NT$1,000 報告是引蛇入甕——真正的 LTV 在後續深度諮詢（NT$3,000-8,000）和關係人報告（伴侶/親子）。報告是漏斗頂部，不是終點。
後端設計：報告末頁設「深度解析」升級入口
策六
🎭 迷敵策 — 賣的不是命理，是解脫感
表面是命理報告，本質是「讓人看懂自己為何這樣」的解脫感。行銷語言從「準確命理」轉向「終於看懂自己」，觸及更廣的非命理信徒受眾。
品牌語：「你一直是這樣的人，只是沒人告訴你」
策七
🏗️ 固本策 — 口碑護城河
AI 命理最大風險是「不準被截圖傳播」——一個「超不準」的分享，比十個「超準」破壞力更大。報告品質持續迭代就是澆灌口碑護城河的根基。
建立準確度回饋機制：使用者評分 → 自動調優
策八
🤝 連橫策 — 盟友網絡
瑜伽老師、身心靈 KOL、成長型讀書會版主、國際人類圖認證師——有受眾、有信任度、需工具。給白標版或高分潤合作，是不燒廣告費的渠道建設。
優先接觸：FB 人類圖台灣官方社群管理員
策九
⏳ 持久策 — 從交易到關係
命理報告一次性是命門。設計年度版（流年分析）、家族版（親子/伴侶）、職涯版（換工作/創業決策），讓使用者有理由多次回來。
路線：基礎報告 → 深度諮詢 → 年度訂閱 → 企業版
🎖️
九策仲裁優先級：策七（固本）→ 策一（速攻）→ 策五（引蛇）→ 策二（圍城）→ 策九（持久）。固本必須先行——報告品質是所有其他策略的地基。品質未達「超準」門檻前，大規模推廣會加速口碑損傷。
