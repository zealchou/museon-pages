03 — Revenue Model

顧問輔導費撥款機制

客戶月費固定 $6,000 不打折。介紹的人有付月費 → MUSEON 另外撥 $2,000 顧問輔導費給你。不是省錢，是賺錢——心理帳戶完全不同。

角色金額說明

兩代輔導金情境說明

📋
情境一：顧問(A) → 客戶(B) → 延伸客戶(C)

三位都有固定繳月租費 $6,000：

  • 顧問 A 拿到：客戶 B 的 $2,000 + 延伸客戶 C 的 $1,000 = 每月 $3,000
  • 客戶 B 拿到：延伸客戶 C 的 $2,000 = 每月 $2,000
📋
情境二：顧問(A) → 客戶(B) → 延伸客戶(C) → 客戶(D)

四位都有固定繳月租費 $6,000：

  • 顧問 A：拿不到客戶 D 的輔導金（最多兩代）
  • 客戶 B：只拿到延伸客戶 C 的 $2,000。要拿到客戶 D 的輔導金，需要上課＋考試＋取得認證資格（付學費）
  • 客戶 C：拿到客戶 D 的 $2,000
關鍵設計：兩代封頂 + 認證升級

一般客戶只能領一代（直接介紹人的 $2,000）。要領兩代，必須取得認證顧問資格。這個設計同時達成兩個目的：
1. 防止無限層級的分潤疑慮
2. 推動客戶主動升級為顧問——「想賺更多，就學更深」

飛輪邏輯

介紹 3 人 = 每月額外收入 $6,000（3 × 2,000），等於覆蓋自己的月費 → 推薦動力極強 → 客戶自然成為推廣者 → 獲客成本趨近於零。輔導金撥款無上限，介紹越多、賺越多。

賺錢 > 省錢：不是「你的錢變少了」，而是「你多了一筆額外收入」。客戶的推薦動力從「幫自己省錢」升級為「幫自己賺錢」。

06 — Community Moat

社群護城河

產品是入場券，社群才是護城河。真正黏住人的不是功能，是歸屬感和持續價值。

🔥
社群活化三要素
  • 有東西可聊 — MUSEON 每天的診斷、盲點發現就是天然內容。「今天 MUSEON 跟我說我的定價邏輯有問題」自然引發討論。
  • 有人帶節奏 — 顧問 = 社群 AM。發文、回文、點名、帶話題。這是 Course 2 最該教的核心技能。
  • 有新東西可學 — MUSEON 新功能開發與迭代內容持續釋出，加上來自不同客戶的 Skill 使用分享，社群永遠有新鮮素材。
  • 有階層感 — 新人看到老手的成果分享，產生「我也要到那個程度」的慾望。可用 Skool 的積分排行榜機制。
隱藏的數據飛輪

社群裡的對話 = MUSEON 的訓練資料。100 個老闆聊經營問題 → MUSEON 學到更多決策模式 → 判斷更準確 → 客戶更黏。這是 ChatGPT 永遠做不到的——它沒有封閉社群的垂直數據。

🛠
Skool 定位

適合用的地方：顧問培訓 + 社群的前台載體。課程內容、交流、排行榜（誰落地最多客戶）。

不適合的地方：MUSEON 本身的訂閱和折抵機制——兩套帳分開，Skool 管社群，MUSEON 管營收。
