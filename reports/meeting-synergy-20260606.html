議題 1｜SIM LIFE 人生市集商模架構

利害關係人地圖

參與者（C 端）

  • 求職者：體驗不同工作職能，探索方向
  • 換跑道者：自我認識、探索新可能
  • 提供人的機構：學校、大專院校，透過 CSR 帶學生（現階段以張秀菊為主）

攤位主（B 端）

  • 大 B（企業聯盟/並牌公司）：出資方，目的為企業形象曝光、ESG 指標
  • 小 B（個別公司）：旗下子公司擺攤，目的為招募潛在人才

服務提供者

  • 教練 / 老師 / 專家：現場帶領復盤職涯規劃；現場小額收入，真正目標是後續陪跑費
  • 志工：政府時間銀行制度（累積時數換服務）+ 旅遊景點免費資格
盈利邏輯
  • 現場收攤位費 + 參與費 → 頂多打平（歷史實證：收過 $5,000/攤位 + $1,200/人，最終打平）
  • 真正利潤來自後端系統：AI 教練包月 + 陪跑服務分潤 + 企業 HR 數位化服務
  • 品牌冠名贊助為額外收入

活動記錄數位化構想

  1. 參與者填寫「紙本記錄卡」（格子/勾選形式，類似考試答案卡）
  2. 活動結束後掃描上傳給 AI Agent
  3. Agent 自動建立個人檔案（記錄「第一次玩的樣子」）
  4. 多次參與後可看見改變軌跡
  5. 資料可 pass 給企業端 HR，作為員工培訓數位依據

⚠️ 先決條件：送 Zeal Agent 測試「空白模板 vs 填過的模板」能否被正確識別，再優化欄位設計
