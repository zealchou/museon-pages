WHY IT IS HOT

它為什麼突然很紅？

不是已被證實「全球性能第一」，而是三件事同時發生：免費、百萬 token 長脈絡、匿名身分帶來的好奇與測試潮。

  1. 試用門檻低：OpenRouter 目前列出輸入與輸出皆免費；對開發者來說，可不先承擔每 token 成本就測 agent 和長資料工作流。官方價格與路由頁
  2. 規格很吸睛：1M context、131K output、文字／圖片／影片輸入，加上工具呼叫，剛好對準「整包 repo、長規格、長程 agent」的使用場景。官方規格
  3. 匿名本身就是話題：媒體報導把焦點放在「誰做的」；目前市場傳聞指向 Z.ai 的 GLM 或 Microsoft MAI 等，但沒有公司承認。TechCrunch 報導
  4. 使用量很快上升：OpenRouter 的程式模型集合頁在本次查證時把它列為第 2 名、14.2% 的週使用占比。這是平台使用量排行，不是能力測評或「排行榜第一」的證據。OpenRouter Programming collection

重要界線「它可能是 GLM」只是推測，不能當採購或部署依據。理由是某些測試者觀察到 API／tokenizer 行為相近；但官方唯一確認的是匿名第三方。連媒體也把 Z.ai、Microsoft 等說法列為未證實的猜測。來源

關於性能：我沒有找到模型作者公布的技術報告、可重現基準測試，或一個能支持「它在某公開權威榜單第一」的官方來源。故不應把它描述成性能已被獨立證明的冠軍；目前可證實的是它被定位為 coding／agentic reasoning 模型，且使用量很高。

LOCAL OR CLOUD?

可以在我們自己的機器上跑嗎？

結論｜目前不行截至 2026-08-25，沒有官方公開權重，也沒有可用的 GGUF／量化版本。

Hugging Face 上唯一顯眼的 0xKitkat/Ox-Alpha-GGUF 自己明寫：它是 placeholder、目前沒有權重、也不隸屬於開發者。這不是「慢慢下載就能跑」的模型檔。Hugging Face 模型卡

想做的事現在是否可行白話條件
透過雲端試用可以OpenRouter 帳號與 API key、網路；不需要自己的 GPU。API 使用 OpenAI 相容的 chat-completions 端點，將 model 指定為 stealth/ox-alpha。官方 Quickstart
做內部原型／非機密測試可以，但要設限因為目前官方價為 $0，適合先用小批工作比較品質；仍應留意免費額度／路由可能改變，以及供應商留存輸入輸出。
把它放入自己 GPU／離線部署不可以缺的是合法可下載的原始權重與授權，不是缺一張更大的顯卡。因此目前沒有可信的 VRAM、CPU 或磁碟需求可報。
下載 GGUF 給 llama.cpp／LM Studio不可以目前看見的 GGUF 名稱只是追蹤頁，沒有模型檔；請不要下載任何來源不明、宣稱是 Ox Alpha 的權重。

OpenRouter 的一般 API 方式需要 Bearer API key；官方 FAQ 也說明免費模型仍可能受帳戶／信用額度影響的 rate limit 約束。API Quickstart、FAQ 與免費模型 rate limits

DECISION

給我們的務實建議

  • 要嚐鮮：可以用它跑一組不含客戶或機密資料的 coding／長文件測試，拿既有任務和目前模型做盲測比較。
  • 要接進正式產品：先不要。匿名供應商、preview 路由與免費價格都可能改；也沒有公開權重讓我們留一份自管備援。
  • 要「本機可控」：把 Ox Alpha 排除在外，改選已公開授權、權重與量化檔都可驗證的模型；Ox Alpha 至少要等官方公布權重與 license 後才值得重新評估。
  • 要保護資料：不要用它處理私有 repo、客戶識別資料、營運機密或憑證。官方雖稱不訓練，但明確告知匿名供應商會保留輸入與輸出。
