Lecture-YouTube-uploader 隱私權政策

最後更新：2026 年 8 月 28 日 ・ 適用對象：本應用程式的唯一使用者

這支應用程式是什麼

Lecture-YouTube-uploader 是周逸達（Zeal Chou）為個人用途開發的自用工具， 唯一功能是把他本人製作的講課影片、字幕與縮圖，上傳到他本人所有的 YouTube 頻道。

這支工具不對外提供、不公開發行、沒有第三方使用者。 它在開發者本人的個人電腦上執行，不是網站、也不是雲端服務。

會取得哪些資料

當使用者（即開發者本人）授權時，本應用程式會向 Google 取得以下 YouTube Data API 權限：

  • youtube.upload／youtube／youtube.force-ssl —— 用於上傳影片、上傳字幕、設定影片標題與說明。

授權完成後，Google 會發給本應用程式一組存取憑證（access token 與 refresh token）。 這是本應用程式唯一持有的資料。

資料怎麼被使用與保存

憑證只儲存在開發者本人電腦的單一檔案中，檔案權限設為僅擁有者可讀寫（0600）， 並已排除於版本控制之外，不會上傳到任何伺服器、不會傳送給任何第三方。

憑證僅用於呼叫 YouTube Data API 完成上傳。本應用程式不會讀取、分析或散布 頻道的觀眾資料、留言、訂閱者名單或任何其他人的個人資料。

不會做的事

  • 不收集任何第三方（觀眾、訂閱者、其他 Google 使用者）的個人資料。
  • 不販售、不出租、不交換任何資料。
  • 不將取得的資料用於廣告、分析、AI 模型訓練或任何與上傳影片無關的用途。
  • 不刪除既有影片，也不變更任何影片的公開狀態——這兩件事保留由使用者本人在 YouTube 網站上手動執行。

如何撤銷授權

使用者可隨時前往 Google 帳戶的第三方應用程式頁面 移除本應用程式的存取權。撤銷後，本應用程式立即失去所有存取能力； 留在本機的憑證檔案也會隨之失效，並可直接刪除。

遵循的規範

本應用程式對 Google 使用者資料的使用與轉移，遵守 Google API 服務使用者資料政策， 包含其中的「有限使用」（Limited Use）要求。 使用本應用程式亦即同意 YouTube 服務條款； Google 的隱私權處理方式請見 Google 隱私權政策。

政策變更

若本應用程式的功能或資料處理方式有所改變，本頁面會同步更新，並更新頁首的「最後更新」日期。
