Chapter 09 · Risk Matrix
風險矩陣
五大風險 × 機率衝擊評估 × 應對方案
死法② 口碑炸彈
機率：高 · 衝擊：極高
🔴 極高優先
一份品質差的報告 + 一個有影響力的用戶 + 一篇 PTT/Dcard 文 = 品牌信任歸零。命理市場的口碑傳播速度比一般消費品快，負評也是。AI 命理若被質疑「不準」，公關危機難以挽救。
應對方案：MVP 先用單系統，融合漸進加入。設計自動品質評分機制（語意一致性檢查），低評分報告觸發人工審查隊列。NPS 自動收集，低於 7 分立刻人工介入。
死法③ 推廣者背刺
機率：中 · 衝擊：極高
🔴 極高優先
分潤機制會吸引大量以佣金為主要動機的推廣者。當市場競品出現更高分潤，推廣網絡可能在三個月內瓦解。分潤若追蹤不透明，信任崩潰速度比建立快 10 倍，推廣者出走且帶走下線。
應對方案：Week 3 前完成分潤追蹤自動化系統（透明是信任基礎）。設計推廣者忠誠度計畫（累積 50 份以上享永久較高分潤比例）。建立推廣者保護機制，防止平台越過推廣者直接觸達客戶。
死法① 監管風險
機率：低 · 衝擊：極高
🟠 高優先
台灣消保法對「預測性服務」有特殊規定。占卜/命理服務在部分地區有法規灰色地帶。若用戶因看了報告做財務或重大決策後悔，法律責任歸屬需事先設計。
應對方案：定位為「洞察報告」而非「命理預測」。報告上加入完整免責聲明架構（「僅供參考，非專業命理諮詢」）。諮詢法律顧問確認合規框架，上線前完成。
死法④ API 漲價 / 政策變動
機率：中 · 衝擊：高
🟠 高優先
系統高度依賴 Claude/GPT API。供應商調整定價或使用條款（如「不得用於命理/占卜相關服務」），成本結構和合規性都可能崩潰。N 套並行 agent 的 token 消耗是競品的 N 倍。
應對方案：建立 API 成本監控儀表板，設定每份報告 token 上限（NT$100 以內）。評估部分命理計算用 CPU 本地計算（八字排盤、紫微本命盤），減少 LLM 依賴。設計多供應商備援路徑。
死法⑤ 自我迭代停滯
機率：中 · 衝擊：高（長期）
🟡 中優先
第一版報告讓用戶驚艷，但六個月後用戶已看過三次，期待值提高了。若報告內容沒有持續進化，回購率崩潰。命理知識本身（哪些系統、如何融合、準確性如何驗證）是高度隱性的知識資產，若核心設計者離開，優勢快速消散。
應對方案：將各命理系統計算邏輯、融合規則、口吻設計全部文件化並版本控制。建立「命理師顧問委員會」（2-3 位有公信力命理師）作為融合品質的持續審核資源。設計用戶回饋學習機制，數據飛輪驅動持續迭代。
