② 沒有 API／MCP 時，有哪些自動化上傳管道？

方式是否可免每集手動上傳證據與邊界
YouTube Playlist 匯入是，但須先在 SoundOn Hosting 後台完成匯入設定。官方支援匯入所有或個別 Playlist；完成後，新上傳至 YouTube 的集數會持續自動匯入。同步檢查頻率為每 36–48 小時，另有處理延遲。私人 Playlist／私人影片不會被匯入，Premier 不在自動同步類型內。官方 YouTube 匯入說明
SoundOn 後台排程不免上傳；可在已上傳後設定未來上線時間。SoundOn 官方功能頁說明可設定未來發布時間；這是後台排程，不是外部工具送檔的介面。官方多平台上架／排程頁
RSS 對收聽平台更新不免向 SoundOn 上傳；免重複到每個收聽平台手動發布。至少一集已發布後可提交 RSS；各平台通過後，後台上傳的新集數會同步。每一個收聽平台只需首次手動提交一次。官方建立新集數說明

Zapier／Make／IFTTT：本次在三者的官方目錄檢視入口及定向搜尋中，沒有取得可證明「建立 SoundOn 集數」或「上傳音檔到 SoundOn」的整合頁，故查無可驗證的官方或第三方直接上傳整合。查詢詞為 SoundOn Zapier Make IFTTT integration podcast upload、site:zapier.com/apps "SoundOn"、site:make.com/en/integrations "SoundOn"、site:ifttt.com SoundOn；可作證的 SoundOn 專用發布整合頁為 0 筆。檢視入口：Zapier App Directory、Make App Integrations、IFTTT Services。這代表本次沒有找到可驗證的方案，並非對這三個市場的永恆、絕對否定；若日後有整合上架，應以該整合的實際動作頁與 SoundOn 授權文件重新確認。

③ YouTube 音軌要怎麼沿用為 Podcast？

優先選擇：官方 YouTube 匯入，而非自行從影片抽音檔

若影片／頻道由你控制，SoundOn 已提供 YouTube 匯入流程：在 Hosting 首頁選「匯入 Podcast」→「YouTube 匯入」，依指示以頻道資訊驗證，再選擇全部或個別 Playlist。對這個流程，官方沒有要求你先輸出純音檔或先轉 MP3；因此在此官方匯入路徑下，本報告查到的文件沒有列出使用者須手動轉檔的步驟。來源：官方 YouTube 匯入說明。

但已匯入的既有集數不會因 YouTube 後續修改而再次同步；官方要求回到先前匯入的單集音檔更新。新上傳影片才會持續自動匯入，且需預留 36–48 小時的抓取週期和處理時間。來源同上。

若改走手動上傳：必須重新輸出「真正的 MP3」

  • SoundOn 目前只接受 MP3，單檔須 小於 250 MB，長度未限制。
  • 官方建議：44,100 Hz 取樣頻率、16 或 24 bit、192 kbps。
  • 不能把 .aac／.m4a 只改副檔名為 .mp3；必須是實際轉出的 MP3。官方 FAQ 亦提醒，假 MP3 可能造成平台播放問題。

來源：官方音檔規格、官方 FAQ、官方播放排錯。

音質資訊的誠實邊界：本次查到的 SoundOn YouTube 匯入文件沒有說明匯入後使用的音訊 codec、bitrate、是否重新編碼，或是否保留原始音質。因此不宣稱「直接匯入一定保留原音質」或「一定會降質」。若音質控制是必要條件，能被官方規格直接支持的路徑是：從你持有的原始製作檔另行輸出符合上述 MP3 參數的純音檔，再用網頁後台上傳。

④ 若走手動：SoundOn 官方上傳流程

  1. 使用網頁版 Hosting 平台（官方說明：不能用手機上傳）。
  2. 進入「單集列表」，按右上「＋新增單集」或側欄的「＋」。
  3. 先上傳符合規格的真實 MP3。
  4. 填寫必填資料：標題、描述、上架類型，以及是否同意動態廣告置入；可選擇季／集、預計發佈時間與單集封面。
  5. 選擇「暫存草稿」或「儲存」正式發布。
  6. 至少有一集已發布後，才可把節目的 RSS 提交到收聽平台；通過後，各平台會隨 SoundOn 後台的新集數更新。

來源：SoundOn：如何建立新集數？、SoundOn：音檔規格／裝置限制。

可採取的決策

要由 agent 直接送檔發布：目前沒有可查證的 SoundOn API／MCP 可採用，不能把瀏覽器自動化或未文件化請求當成官方支援方案。

來源本來就是 YouTube：採官方 YouTube 匯入，接受設定後的同步週期與既有集數不回同步的限制。

要可控音質且每集內容不同：輸出真實 MP3（< 250 MB；建議 44.1 kHz、16/24 bit、192 kbps）後，以網頁後台手動上傳並視需要排程。
