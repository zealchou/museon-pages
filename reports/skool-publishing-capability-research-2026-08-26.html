Skool 能否發布「影片＋逐字稿＋Agent Skill 檔」？

2026-08-26｜僅採用 Skool 官方公開文件｜研究結論

可以，但正式教材應放在 Classroom lesson/page。Skool 官方已明載 Classroom 有影片、可搜尋逐字稿與可供會員檢視／下載的 resource file；Community 則適合作為上線公告與討論入口。Community 的一般附件、長文與檔案大小上限，官方公開資料未提供可核對的規格。

「查無」指本次檢索到的 Skool 官方公開 Help Center／官方頁面未見該規格，不等於平台技術上必然沒有。

bot、未公開端點或瀏覽器自動化不建議，且不能視為官方核准。Skool 官方政策禁止以 bots 發 post/comment/message，並要求不要做 scraping 或 automation requests。Platform policy

因此，這次的內容發布應走 Skool 瀏覽器內的 Classroom 編輯流程；不要以未公開端點或自動化繞過。

4. 檔案下載

Classroom：能直接上傳。群組 owner 或 admin 可依 Course → New Page → Edit → ADD → Add resource file 上傳；官方說文件可供會員在 Skool 內檢視或下載，並稱可加入任何 document format。How to upload a PDF or any document?

但官方未特別點名 `.md`、`.zip`，也沒有公開大小上限或 MIME 白名單。因此 resource file 是正確的官方入口，仍應先以非敏感測試檔驗證這兩種副檔名在目前帳號／版本的實際接受情況。

外部 Google Drive／GitHub 不是 Classroom 的必要條件。若要版本控制或備援可自行使用；但若堅持把檔案放在 Community，因 Community 附件未獲官方文件確認，外部連結會是較保守的替代方案，而不是 Skool 官方保證的 Community 檔案功能。

建議的發佈流程

  1. 在 Classroom 建立或選定 course，先維持 draft。
  2. 建立 lesson/page：加入 YouTube、貼上完整逐字稿、加入 transcript 與 Agent Skill resource file。
  3. 以有權限會員帳號測試影片播放、逐字稿完整性與檔案下載；尤其測 private YouTube 行為。
  4. 發布 course/page，並在 Community 發公告連回 lesson；需要時把公告釘到 course page。

未證實事項

  • Community 貼文字數上限、完整富文字／Markdown 格式、一般附件格式與大小限制。
  • Classroom page／transcript 字數上限，以及 `.md`、`.zip` 的確切接受規則與大小上限。
  • YouTube private 影片的 Skool 會員端嵌入播放行為。
  • 可寫入 post/course/page/attachment 的官方公開 REST API。
