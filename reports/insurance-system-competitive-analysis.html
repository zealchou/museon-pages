市場定位分析

這套系統定位精準——它不是 CRM，不是業績報表，而是一套專為「行為紀律追蹤」設計的工具。 保險業的核心管理挑戰，在於「到底每個業務有沒有做到基本功」，而非只看結果數字。

填補的市場空缺

🎯 行為追蹤 ≠ 業績追蹤
市場上 95% 的系統追蹤的是「結果」（保費、FYC、成交數）。本系統追蹤的是「過程行為」——每日三訪、早會出席、問卷完成。

藍海定位 行為 → 結果的因果鏈，是主管真正需要的洞察。
🟢 紅綠燈介入機制
一般系統資料是靜態的，主管需要自己看、自己判斷。紅綠燈自動評分（綠/黃/紅）讓主管只需關注「需要介入」的人員，大幅降低管理認知負荷。

效率槓桿 10 人團隊節省主管每週 3–4 小時追蹤時間。
🔒 資料主權優勢
保險業監理嚴格，業務行為資料屬高敏感。架設在客戶自己的伺服器，資料不經第三方 SaaS，完全符合金管會合規要求與內控需求。

合規加分 SaaS 方案普遍難以通過法遵審查。

目標客群定義

主要購買者：保險公司區部主管 / 處經理，管理旗下業務 10–50 人，過去靠 LINE 群組 + Excel 追蹤，每週花大量時間催打卡、整理資料、在早會唸名單。

核心痛點：「我知道誰沒做基本功，但我要花太多時間去確認和記錄。」

次要使用者：業務員本人（每日回報）、公司稽核部門（合規紀錄）、HR（人員留任分析）。

系統定位矩陣

遊戲化黏著度策略（使用率保證）

系統最大風險不是「做不出來」，而是「做出來沒人用」。保險業務員習慣自主節奏，強制填報容易引起抗拒。以下遊戲化機制讓填報行為變成自我驅動的正向習慣，主管不需追人，數據自然流入。

設計原則：遊戲化不是「好玩」——是把正確行為包裝成讓人想做的事。每個機制背後都有對應的行為心理學依據，針對保險業務員的競爭心理與自主感設計。

8 大核心遊戲化機制

🔥 連勝系統（Streak）
連續 5 天完成任務顯示「5連勝🔥」徽章，7 天額外加分。

原理：損失厭惡——業務員不想打斷連勝，自主維持填報節奏。
⭐ 等級制度（Level Up）
新手→進階→精英→傳奇，每個等級有獨特稱號與特權（如優先看主管回饋）。

原理：成就感驅動——等級可見，社交比較產生持續動力。
🏆 週排行榜（Week Board）
只顯示「前三名 + 自己的名次」，不公開全體排名。

原理：適度競爭——排名可見但不羞辱末位，鼓勵追趕而非放棄。
🎯 週挑戰任務（Weekly Quest）
每週 3 個挑戰（如「連續 3 天第一個回報」）完成可得獎章。

原理：短期目標——讓人每週都有新動力，不只是重複同樣動作。
🤝 師徒連結積分
主管陪跑完成任務後，師徒雙方各得積分。主管的支援行為變得可追蹤可獎勵。

原理：讓主管有動機主動陪跑，而非只是催促。
🎉 里程碑慶典
8 週完成率 ≥ 80%、月度達標等節點推播慶典通知，讓數字變成「值得慶祝的事」。

原理：正向強化——不只記錄失敗，也慶祝成功。
💪 連勝復活機制
連勝中斷後有「復活週」，完成當週目標可恢復。降低中斷後的心理門檻。

原理：減少「反正已經斷了不如放棄」的心理沉沒成本。
🏅 成就徽章牆
個人主頁顯示已解鎖徽章，可分享。成為業務員的「數位勳章」。

原理：身份認同——徽章成為業務員自我介紹的一部分，強化行為持續性。
📊 預期效果（參考產業數據）：
導入遊戲化機制的業務追蹤系統，平均使用率提升 40–65%（相較無遊戲化版本）。連勝系統尤其有效——業務員為維持連勝自主填報的比例比強制要求高 3 倍。
🎯 對業主的核心說服點：「買系統容易，讓人用才是挑戰。我們的系統把遊戲化機制內建進去，讓業務員不是因為主管要求才填，而是自己想用。這是其他系統做不到的差異化。」

談判重點建議

從業主立場設計談判策略——哪些功能是必做的高價值核心，哪些可留後階段迭代，以及如何讓業主有信心點頭。

v1 必做（高價值，不可妥協）

MUST 紅綠燈評分引擎
這是整個系統的核心差異點。沒有紅綠燈，系統就只是「數位版 LINE 打卡」，無法讓主管快速判斷異常。

評分邏輯需可彈性設定（各指標加權比例），不能是固定公式。
MUST 主管儀表板（今日總覽）
主管使用最高頻的功能。今日有幾人達標、幾人黃燈、幾人紅燈，必須在一個畫面看完。

若儀表板不夠直觀，使用率將大幅下降，影響系統價值感知。
MUST 任務設定靈活性
不同保險公司、不同主管對「基本功」定義不同。任務必須可設定、可加減項目，否則系統無法跨客戶複用或因應各家特殊規定。
MUST 照片佐證 + 審核流程
保險業主管最怕業務「填假資料」。照片佐證是系統公信力的來源。

審核工作流（業務提交 → 主管審核/退回）是管理閉環的關鍵，必須在 v1 完成。

v1 已包含（無需另外付費）

  • PWA 前端 — 業務員手機瀏覽器直接使用，無需安裝 APP。主管端亦可手機操作。
  • 照片佐證 + 審核流程 — 業務員提交照片，主管線上審核 / 退回，閉環管理。
  • 遊戲化積分系統 — 連勝 / 等級 / 週排行榜全部含括在 v1 交付範圍內。

後續可迭代（由業主需求決定，另行報價）

  • LINE 推播提醒整合 — v1 可先用系統內通知替代，後續再接 LINE Notify / LINE Bot。
  • 自動化報表排程發送 — v1 主管手動匯出即可，後續加排程自動寄送 PDF 報表。
  • 多團隊 / 跨區比較分析 — 集團型保險公司才需要，一般 10–50 人團隊 v1 已足夠。
  • MUSEON AI 對接 — 系統已預留介面，待數據累積 3–6 個月後可啟動（詳見第 07 章節）。

談判建議話術框架

對「要不要考慮一下」的拖延：
「這套系統是架設在您自己的伺服器上，資料完全屬於您，沒有月費，沒有訂閱綁定。最大的風險不是買了後悔，而是三個月後才決定，那時又多花了 3 萬的人力成本在追打卡和整理報表。」
