Memory Five Dimensions

記憶五維度：人、事、時、地、物

MUSEON 的記憶系統超越「聊天紀錄」的層次，對每一則資訊沿五個維度進行結構化儲存與索引，讓它能在未來精準召回最相關的脈絡。

人
Who
誰說了什麼、對方的角色與立場、關係強度與互動模式——建立動態人物網絡。
事
What
發生了什麼事、決策內容、行動項目、結果與後續影響，形成可查詢的事件圖譜。
時
When
時間戳記、時序關係、週期規律——讓 MUSEON 知道「這件事現在是否仍然相關」。
地
Where
情境脈絡、場景定位——會議室裡的一句話 vs 私訊裡的告白，意義截然不同。
物
What Object
涉及的專案、產品、文件、資產——把資訊錨定到具體的業務對象，不再凌空漂浮。
機制說明
每次對話結束後，L4 CPU Observer 自動萃取五維度資訊寫入向量資料庫（Qdrant），並觸發語義索引。下次提問時，MUSEON 在 < 100ms 內完成相關記憶的向量搜尋，無感召回精準脈絡——不需要你每次重新解釋背景。
Cognitive Profile · 5 Layers

五層認知輪廓：真正懂你的思維方式

MUSEON 不只記住你說過什麼，更會主動建構你的認知輪廓——讓它逐漸內化你的思考邏輯，而不是每次都重新適應。

L1
認知風格（Cognitive Style）
你習慣用系統思維還是直覺跳躍？傾向第一性原理還是類比推演？MUSEON 觀察你的提問模式，逐漸校準自己的回應框架與資訊密度。
L2
方法論體系（Methodology Stack）
你使用哪些思維框架？Business-12、SSA、X-Model、DHARMA——MUSEON 記住你的工具箱，在合適時機主動套用，不用你每次說「用 X 方法來分析」。
L3
審計標準（Quality Standards）
你對什麼品質不滿意？曾糾正過哪些失誤？這些都會成為 MUSEON 的內化標準——它會在輸出前自我審計，用你的標準過濾，不用你反覆教同樣的事。
L4
能力邊界（Capability Boundaries）
哪些任務你已經很強、不需要 AI 提意見？哪些領域你需要深度協助？MUSEON 知道在哪裡補位、在哪裡收手，成為真正的共同創作者而非管理工具。
L5
工作流偏好（Workflow Preferences）
你喜歡先有大綱再填細節？還是邊做邊演化？上午決策、下午執行？MUSEON 學習你的節奏，讓協作摩擦趨近於零。
Hermes Mode · Auto Skill Forge

Hermes 模式：自動技能鍛造，越用越強

一般 AI 工具每次對話都從零開始。MUSEON 的 Hermes 模式會在你解決複雜問題後，自動將成功路徑鍛造為可重複呼叫的 Skill——知識不只保存，而是進化。

01
觸發偵測
任務完成後，系統自動偵測是否命中鍛造條件：複雜多步驟任務、試錯後找到正確路徑、使用者糾正後的新方向……
02
路徑萃取
從本次對話中萃取有效工作流——哪些步驟是關鍵轉折點、哪些工具組合最有效、前提條件是什麼。
03
Skill 鍛造
將萃取出的工作流結構化為 ACSF 格式的 Skill 定義，含觸發條件、執行步驟、品質護欄，自動安裝至技能庫。
04
語義索引
新 Skill 立即向量化寫入 Qdrant，下次遇到類似場景時，MUSEON 在路由時自動匹配並呼叫——無需你記住 Skill 名稱。
⚡
護欄設計
同一任務最多觸發一次；若現有 Skill 已覆蓋此場景則跳過；鍛造在背景進行，不中斷主線對話。目前技能庫已累積 100+ 個客製化 Skill，涵蓋商業分析、品牌設計、財務建模、市場情報等領域。
