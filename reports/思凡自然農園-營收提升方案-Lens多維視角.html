🌿 社會企業型農場 📊 營收優化策略 📅 2026年6月

核心洞察

思凡面臨的不是「銷售問題」，而是 「模式成本結構失衡」。 一級（生產）+二級（加工）並行，用低產能人力成本執行高合規要求的雙軌製造，導致每個單位的淨邊際被吃掉一半。 營收的提升不能只從「賣更多」入手，必須先從 「改成本結構」和「重定位」 開始—— 讓原本的成本重擔轉變成差異化優勢。

1
商業視角：模式診斷與重定位

現狀分析

  • 雙軌製造成本模式： 一級生產（香草種植）+ 二級加工（乾製、飲料、醬）同時進行，導致配置成本、儲存成本、品管成本疊加
  • 收購價vs零售價缺口： 向協會合作夥伴（朱芳嫻網絡）供應時，收購價格受社企考量壓制，但自有加工品邊際有限
  • 庫存堆積風險： 「堆了一批」表示銷售預測偏低或管道單一，現金流被佔用

重定位機會（從「供應商」→「品牌」）

升級方向： 不再止於「代工+供貨」角色，改為「故事型原產地品牌」

  • 「精神障礙友善農場」認證： 強化與朱芳嫻協會的聯動，面向ESG採購企業、CSR預算方強調「僱用障礙者參與生產的香草品牌」——這是差異化定位，能撬開B2B企業採購和公益認購
  • 「台東原產地」故事： 地理標誌+原產地溯源，針對城市高端消費者（願為理念溢價）
  • 「小批量、零農藥」高端線： 用「低產能人力」反轉成優勢——手工、細緻、品質穩定，針對禮品市場和企業贈禮

定價策略調整

  • 分層定價：
    • 低端線：向協會+供應商維持現價（穩定現金）
    • 中端線：自有線上品牌（官網、社群），+30% 邊際
    • 高端線：故事型禮品組合、企業贈禮、CSR採購，+50~70% 邊際
  • 訂閱制試點： 推「每月香草盒子」予高端消費者，提升LTV、穩定現金流

社會視角：使命槓桿與利益相關者

核心使命重述

思凡不是「純商業農場」，也不是「純公益」——是「透過創造商業價值來支撐社會使命的社會企業」。

使命層：「讓精神障礙者的勞動產出被看見、被尊重、被購買」

利益相關者拆解與槓桿點

  • 朱芳嫻協會網絡（供應端/傳播端）
    • 現狀：優惠收購價供應
    • 升級機會：共建「企業CSR採購聯盟」——朱芳嫻協會引薦企業客戶，思凡提供高邊際的品牌產品，協會獲分潤或贈禮折扣
  • 障礙者員工與家庭（受益端/品牌見證人）
    • 現狀：獲得工作機會
    • 升級機會：員工故事、作品集、短影音見證 → 品牌內容資產，提升購買轉化率
  • 企業ESG採購方（購買端）
    • 現狀：無感知
    • 升級機會：建立「ESG香草採購」pitch，對標SDG 5/8/10（性別、工作、不平等），年度採購額可達50~100萬
  • 高端消費者社群（轉換端）
    • 現狀：無
    • 升級機會：Instagram/FB 故事型行銷，建社群（1萬粉→年度複購轉化5~8%）

影響力指標設定

  • 障礙者僱用數/人時/薪資倍增
  • 企業CSR合作夥伴數（目標：年內5家）
  • 媒體/社群曝光次數（故事傳播能力）
3
操作視角：供應鏈與成本優化

成本結構重診

核心問題： 「一級+二級並行」導致每個產品環節都要承擔固定成本（場地、設備、冷鏈、品管）

  • 原料成本：30%（生產）
  • 加工成本：25%（勞動、設備、冷鏈）← 高
  • 儲存/物流：20%（堆積風險）← 高
  • 行銷/銷售：15% 左右
  • 淨利潤：10% ← 社會企業可接受，但沒成長空間

供應鏈優化方案（三層級）

方案A：「聚焦差異化」（建議首選）

  • 放棄低邊際的原料供應給協會（或維持最小量穩定關係）
  • 集中生產能力於 高邊際加工品（乾製、飲料、醬、禮品盒）
  • 釋出場地+人力 → 從「堆積」的低邊際原料，轉向「訂製加工」的高邊際產品
  • 預期邊際提升：10% → 25~35%

方案B：「代工+自有並行」

  • 維持與協會的代工關係（社會價值+現金），但建立 SLA 合約與預測協議
  • 同步開發3~5個自有品牌產品線（禮盒、季節限定、聯名）
  • 需增加行銷投入（+5~10% 成本），預期ROI 6~9個月

方案C：「共同製造模式」

  • 與朱芳嫻協會共建「障礙者友善加工廠」——思凡負責原料+製造，協會負責品牌+銷售渠道
  • 利潤分潤（思凡70%、協會30%）
  • 需協商，但長期穩定、社會影響力最大

庫存+物流優化

  • 現有堆積品： 緊急清貨方案（5折內部員購+折扣銷售+捐贈稅務籌畫）→ 釋放現金、降低倉儲
  • 預測改善： 引入簡單的訂單驅動制（接單→製造→出貨），而非預製
  • 小批量多頻次： 利用「高端禮品市場」的特性（訂製、小量、高價），減少庫存周期

財務視角：營收與現金流模型

現狀財務概況（推估）

假設年營收300~500萬（社會企業典型規模）

  • 代工供應（協會）：年營收200萬，邊際10%
  • 零售產品：年營收100~200萬，邊際15%（受庫存拖累）
  • 淨利潤：年度20~30萬 ← 現金流被庫存積壓

12個月營收提升計畫

階段 月份 重點行動 預期營收
現金解放 M1~2 庫存清貨、預測改善啟動 +15萬
產品重塑 M2~4 3~5 高邊際SKU上線、禮盒包裝、行銷內容製作 +30萬
管道拓展 M4~8 ESG企業洽談、社群達成1k粉、合作機構簽署 +50~80萬
訂閱化 M9~12 「月度香草盒」上線、企業年度採購簽約 +100~150萬

年度目標： 營收從 350萬 → 650萬（+86%），淨利潤從 25萬 → 100萬（+300%）

融資與現金流管理

  • 短期（M1~3）： 庫存變現+政府補助申請（農業處、勞動部身心障礙就業補助）→ 緩解現金壓力
  • 中期（M4~8）： 小額融資（20~30萬，社企低利貸或天使投資人）→ 行銷投入、包裝設計
  • 訂閱制現金流： 月收預約金 + 長尾複購 → 現金流穩定性提升

策略視角：競爭優勢與成長路徑

差異化優勢（與競品區隔）

  • 對標對手： 一般香草農場、食品代工廠、社會企業農產品品牌
  • 思凡獨特性：
    • ✓ 精神障礙者友善製造 + 品質穩定（高端市場願意溢價20~30%）
    • ✓ 台東原產地認證 + 小批量手工 → 稀缺性
    • ✓ 朱芳嫻協會背書 → 社會信任度高
    • ✓ 一級+二級垂直整合 → 品質控制全程掌握

市場切入順序（優先級排序）

第一優先：企業ESG採購市場

  • 年度採購額穩定、決策週期3~6個月、CSR預算充足
  • 切入方式：透過朱芳嫻協會引薦 + Zeal 的顧問網絡 → 精準觸達
  • 目標客戶：年營收5億+上市公司、金融機構、製造業 CSR 部門
  • 年內目標：5家企業 × 年度 30萬 = 150萬營收

第二優先：高端消費者社群（城市、線上）

  • Instagram/Facebook 故事型行銷 → 月度香草盒訂閱制
  • 目標客戶：30~45歲、城市專業人士、社會意識強、願為理念消費
  • 年內目標：500名訂閱戶 × 月均500元 = 年度 300萬營收

第三優先：禮品/贈禮市場

  • 企業員工禮物、高端禮品零售 → 毛利30~50%
  • 合作對象：百貨精品店、電商禮品專區、社企商城
  • 年內目標：50萬營收

核心競爭力養成（18個月）

  • 故事型品牌資產： 障礙者故事庫、製造過程紀錄、社群內容 → 年內達10萬粉絲基礎
  • 高端供應鏈： 穩定 5~10 家企業客戶、建立 SLA → 年度預測性高
  • 產品創新： 季節限定、聯名款、訂製化 → 複購率>50%
  • 人才與營運系統： 專職業務/行銷/品管 → 可複製性提升

⚠️ 核心風險與對策

  • 風險1：企業客戶銷售週期長（決策3~6個月）
    • 對策：M2 即開始企業開發，不要等到M5；透過朱芳嫻協會「背書」加快決策
  • 風險2：品牌建設投入大，ROI 週期長
    • 對策：先從「故事素材免費製作」開始（障礙者員工本身就是內容），減少設計投入；社群有機成長為主
  • 風險3：訂製化生產增加複雜度與成本
    • 對策：建立簡單的訂製模組（禮盒組合、季節限定）而非完全客製，保留可複製性
  • 風險4：障礙者員工培訓與穩定性
    • 對策：與朱芳嫻協會合建「障礙者友善工作流程」SOP，不依賴單人；定期工作坊提升技能

🎯 立即行動優先級（下兩週）

  1. 確認現有庫存數據： 品項、數量、成本、預期清貨時間 → 制定清貨計畫
  2. 訪談3名核心障礙者員工： 拍攝初步故事素材（手機短影音+文字），建立「人物檔案」
  3. 列出3~5個高邊際SKU： 定價結構、成本確認、包裝需求估算
  4. 企業客戶名單初稿： 與朱芳嫻協會、Zeal 確認合作機構與CSR聯絡人
  5. 設計預算估算： 官網改版、禮盒包裝、社群模板 → 洽詢3家設計商報價
