# 視覺語言：紙與墨

沿用 MUSEON 既有的「萬謬書院・紙與墨」那套。**沒有用到任何圖片檔**——
所有質感都是 CSS + SVG filter 生出來的。

## 四個 token

```css
--paper: #F1EDE4;   /* 暖白紙 */
--ink:   #2A2622;   /* 墨（結構、主文） */
--seal:  #B2412C;   /* 印朱 — 全場唯一的飽和色 */
--kaki:  #99531C;   /* 柿褐 — 次要 */
```

墨再分三階透明度：`--ink-2` .68 / `--ink-3` .42 / `--ink-4` .16。
暗色模式整組換掉（紙 `#1E1B18`、墨 `#E4DCCF`、印朱 `#CF5D45`、柿褐 `#D08A45`）。

**最多四個色系**，這是硬規則。

## 指標對到顏色

| 指標 | 顏色 | 為什麼 |
|---|---|---|
| 營收 | 墨 | 中性、結構性 |
| 信任 | 柿褐 | 溫暖、屬人 |
| **內耗** | **印朱** | **全場唯一被允許的飽和色** |

這個對應不是隨便配的，是照 Kairos 視覺規則推出來的必然結果：
規則規定「只准一個小面積的飽和強調（1–10%）」，而這場遊戲裡唯一該刺眼的東西，
就是他們自己造出來的內耗。

**前面九場畫面都是安靜的紙與墨，只有那個數字在燒。**

## 兩個關鍵技法

### 1. 紙紋

`feTurbulence` 生噪點，鋪在最上層 `mix-blend-mode: multiply`，透明度 .07（暗色 .10）。
整段是一個 inline data URI，零外部請求。

### 2. `#rough` 位移濾鏡 —— 純色塊變墨痕

```html
<filter id="rough" x="-12%" y="-12%" width="124%" height="124%">
  <feTurbulence type="fractalNoise" baseFrequency=".9" numOctaves="2" seed="7" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="2.2"
                     xChannelSelector="R" yChannelSelector="G"/>
</filter>
```

任何色塊套上 `filter: url(#rough)`，邊緣就從 CSS 方塊變成蓋印的墨痕。
用在：座位格、票數的印、指數長條。

**這就是「沒有圖也能有手感」的關鍵。**

## 票數用蓋印呈現

一票一個印，各自帶不同角度（`--r`）和墨色深淺（`--o`），依序落下（`animation-delay`）。
比長條圖更有現場感，而且符合紙與墨的世界觀。

## 其他規則

- 字型只有兩套：**楷書**（`LXGW WenKai TC`）寫情境與旁註，**明體**（`Noto Serif TC`）排標題與數字
- **沒有卡片、沒有圓角、沒有邊框**。要分隔用 `box-shadow: inset 0 0 0 1px var(--ink-4)` 的髮絲線
- 數字一律 `font-variant-numeric: tabular-nums`
- 投影幕字級用 `clamp()`，最大到 `7rem`（遠距要看得到）
