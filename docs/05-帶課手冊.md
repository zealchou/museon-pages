## 一句話

讓他們親身撞到「我以為我講了」跟「他真的收到了」中間那道縫。

## 上午流程

| 時間 | 內容 |
|---|---|
| 0:00 | 入座。投影幕出 QR，五個人各選一個位置 |
| 0:10 | 宣布目標：「這一年，營收要多 28，信任最多只能少 28。兩個都做到才算。」 |
| 0:15 | 讀角色卡。強調：卡上的事只有你知道，而且你不能講 |
| 0:25 | **第一輪五場，全程禁語**。每場約 7 分鐘（情境 2／投票 3／結果 2） |
| 1:02 | **第一輪回顧 ← 全場轉折**。投影幕出內耗曲線，先讓他們看三十秒，不要急著解釋 |
| 1:12 | 宣布第二輪規則：「這一輪，你們可以說話了。」只講這一句 |
| 1:15 | 第二輪五場，每場多兩分鐘討論，約 9 分鐘 |
| 1:58 | **結局揭曉**。唸完停三秒，再說：「請把你們的角色卡翻開。」 |
| 2:05 | 結果說明：對公司的甜頭與代價，以及對每個位置各代表什麼 |

按鈕全部在主持人手上，投影幕自己不會動。整場約按 35 次。

## 十場速查

| # | 場次 | 盯著誰 |
|---|---|---|
| R1-1 | 整戶的那張單 | 誰第一個想接？——業務、副總 |
| R1-2 | 那三公分 | 要不要把不完美講出來——倉管、客服 |
| R1-3 | 櫃期 | 倉管的卡上就寫著會延 |
| R1-4 | 電梯 | **伏筆**。誰選了「先照排程走」？ |
| R1-5 | 展示品 | 季底壓力下的底線 |
| R2-1 | 卡住的那張單 | 演的就是他們的真實日常 |
| R2-2 | 安裝主管 | **回收 R1-4**。會聽到「我講了三次，沒有人理」 |
| R2-3 | 建商 | 用現金換數字——會計會很掙扎 |
| R2-4 | 那道刮痕 | 誰去承擔 |
| R2-5 | 明年 | 看他們有沒有提到「交接」 |

**最重要的一刀**：R1-4 選 A 時當下沒有代價，三場後那個人離職並說出原因。
如果他們在 R2-2 露出「啊」的表情，**不要說話**，讓它發酵。

## 主持台

- 一顆大按鈕，永遠寫著下一步是什麼
- 投票進度：看得到誰還沒投
- **代投**：有人手機掛掉時可以幫他投，整場不會卡死
- 退回上一階段／整場重置

## 突發狀況

| 狀況 | 處理 |
|---|---|
| 有人一直不投 | 口頭催一次，再沒有就代投，不要讓全場等一個人 |
| 第一輪有人講話 | 輕輕制止，不要責備。忍不住這件事本身就是下午的材料 |
| **他們第一輪就贏了**（5% 機率） | 問：「你們是知道才這樣選的，還是猜的？」照樣攤牌，一樣有效 |
| 投影幕或網路掛掉 | 紙本備援：十場情境、五張角色卡、白板記分 |
| 進度落後 | 壓縮第二輪討論時間，但**不要砍第一輪回顧**，那是轉折點 |

## 交給下午的三樣東西

1. 一條內耗曲線（兩輪並排）
2. 每個人手機上自己的十場決策紀錄
3. 一個他們親手造成的結局 + 攤開的五張角色卡

下午第一句話不要問感受，先問：
**「第一輪那五場，你有沒有哪一刻想問別人？那一刻你為什麼沒問？」**
