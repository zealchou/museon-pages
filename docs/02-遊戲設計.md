# 遊戲設計

## 核心命題

這個遊戲要讓五個人**親身撞到**一件事：他們手上有全部的答案，只是沒有人開口問。

不是「溝通很重要」——那句話每個人本來就同意，說了不會改變任何事。
是更利的版本：**開會跟交接資訊，是兩件事。**

## 結構

| | |
|---|---|
| 人數 | 5（業務／倉管／會計／客服／副總） |
| 時長 | 約 2 小時 |
| 場次 | 10 場，分兩輪 |
| 第一輪 | 五場，**全程禁語** |
| 第二輪 | 五場，**可以討論** |
| 追蹤指標 | 營收、信任、內耗 |

每一場的循環固定三拍：**情境 → 投票 → 結果**。全部由主持人按鈕推進，投影幕自己不會動。

## 十場在測什麼

| # | 場次 | 測什麼 | 備註 |
|---|---|---|---|
| R1-1 | 整戶的那張單 | 面對機會的本能 | 該衝場 |
| R1-2 | 那三公分 | 要不要把不完美講出來 | 陷阱場 |
| R1-3 | 櫃期 | 壞消息延遲揭露的代價 | 陷阱場 |
| R1-4 | 電梯 | 基層的聲音會不會被聽見 | **伏筆** |
| R1-5 | 展示品 | 季底壓力下的底線 | 該衝場 |
| R2-1 | 卡住的那張單 | 治標還是治本 | 直接演他們的日常 |
| R2-2 | 安裝主管 | 留人的方法 | **回收 R1-4** |
| R2-3 | 建商 | 用現金換數字的誘惑 | 該衝場 |
| R2-4 | 那道刮痕 | 誰去承擔 | 陷阱場 |
| R2-5 | 明年 | 這一年學到了什麼 | 該衝場 |

### R1-4 → R2-2 是整組內容裡最重的一刀

R1-4 如果選了「先照排程走」，畫面只淡淡寫一句：

> 他點點頭，回去工作了。那之後，他沒有再提過任何建議。

**當下沒有任何代價。** 三場之後那個人要離職，而且會親口說出原因：

> 「錢不是問題。是我講了三次的事，沒有人理。」

代價是延遲出現的——這就是現實，也是這個設計最想讓他們感覺到的東西。
主持時如果看到有人露出「啊」的表情，**不要說話**，讓它自己發酵。

## 五張角色卡：拼起來才有答案

這是 hidden profile 結構——每個人手上有一條**只有他知道、而且足以改變結論**的事實。

| 角色 | 只有他知道 | 指向 |
|---|---|---|
| 業務 | 報價高兩成，但這位設計師以反覆改圖、最後砍價出名 | 接 ⚠ |
| 副總 | 老闆下個月談建商合作，最看重這一季成交金額 | 接 |
| 倉管 | 義大利沙發櫃期已確定會延，正式文件還沒發 | 不能這樣接 |
| 客服 | 這位客戶的鄰居去年客訴過，他這次是「試試看」 | 不能這樣接 |
| 會計 | 進口貨款預付、匯率吃掉毛利，客戶只付三成訂金 | 致命 |

**兩票指向衝、三票指向不能衝——但「衝」的壓力來自副總，職位最高的那個人。**
現實裡，兩票常常壓過三票。

五條拼起來的完整因果鏈，就是「兩邊都沒有接住」結局的原文：

> 挪用原料 → 老客戶延遲 → 那個本來就想換供應商的客戶轉單（佔營收三成四）
> → 同時新客戶驗收退回、毛利賠掉六成 → 錢要等九十天 → 而現金只夠兩個月

揭曉時他們會發現：**那段話不是編的劇情，是他們五張卡拼出來的必然結果。**

## 四種結局

由最終的營收／信任決定，四種都到得了：

| id | 條件 | 標題 |
|---|---|---|
| `held` | 營收 ✓ 信任 ✓ | 你們接住了 |
| `hollow` | 營收 ✓ 信任 ✗ | 數字到了，人沒了 |
| `safe` | 營收 ✗ 信任 ✓ | 穩住了，但沒有長大 |
| `lost` | 營收 ✗ 信任 ✗ | 兩邊都沒有接住 |

**五人盲投最可能落在 `lost` 或 `hollow`。這是設計出來的，不是失敗。**

結局之後還有一張「這樣走下去」的說明頁：對公司的甜頭與代價，以及**對五個位置各自代表什麼**。
`lost` 那一組每一句都指回那個人自己的角色卡——

> **倉管**：你早就知道櫃期會延。但從頭到尾，沒有人問你。
> **會計**：你早就知道現金撐不住。但你不想當那個一直說不行的人——所以你沒說。

手機上每個人只會看到自己那一句。

## 內耗指數

**跟他們選什麼完全無關，只看票數有多分裂。**

| 票數形狀 | 內耗 |
|---|---|
| 5-0 | +0 |
| 4-1 | +2 |
| 3-2 | +4 |
| 3-1-1 | +6 |
| 2-2-1 | +8 |

意義：**就算每個人的選擇都合理，只要團隊不一致，公司就在內耗。**

它是三個指標裡唯一只會往上的，也是全場唯一的飽和色（朱紅）。
第一輪禁語它會一路爬升，第二輪可討論之後應該壓平——**結局畫面把兩條線並排，
那個形狀就是整堂課的結論，不用講師講一個字。**

## 為什麼故事設在莉凱

十場全部照他們的實際生意寫：1985 年沙發工廠起家、台中北屯 1600 坪八層樓旗艦店、
進口代理（Pacific Green、Polo Divani）＋ 客製訂製 ＋ 室內設計裝修。

所以痛點不是泛用製造業那套，而是丈量的幾公分、進口櫃期、安裝刮傷、展示品該不該賣、
建商壓七折月結六十天——**他們每天在吵的事。**
